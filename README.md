# Cursada

Aplicación de escritorio (Linux y Windows) para llevar registro de tareas
pendientes y fechas de examen de la facultad, con recordatorios configurables
por notificación de escritorio y email.

## Estado del proyecto
En etapa de planificación. Ver [`CLAUDE.md`](CLAUDE.md) para objetivo, alcance,
metodología, arquitectura y stack tecnológico.
