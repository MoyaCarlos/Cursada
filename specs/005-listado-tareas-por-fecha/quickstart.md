# Quickstart: Listado de Tareas por Fecha Límite (HU-05)

```bash
.venv/bin/python -m pytest -q
.venv/bin/python main.py
```

Escenario manual: crear 3 tareas con fechas fuera de orden (ej: 2026-12-31,
2026-10-01, 2026-11-15) y confirmar que el listado las muestra ordenadas
de la más próxima a la más lejana.
